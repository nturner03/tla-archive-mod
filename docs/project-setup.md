runtime. Transitive resolution is off, and each mod is pinned explicitly to
the pack's version. The same mods are on `localRuntime` so `runClient`,
`runServer`, and `runGameTestServer` load them.

## Verification (2026-10-28)

- `./gradlew build` (JDK 21) produces `build/libs/tla_archive-0.1.0.jar`.
  SHA-256 `f686a8884889c350d657ca8fe243d04ad7ca31deda4d7ec70764ee1ab9b315e4`
  (unreleased development build). Two consecutive clean builds and a build
  from a fresh clone gave the same hash.
- A temporary class that called `IGrid.getStorageService().getCachedInventory()`
  and `FTBTeamsAPI.api()` compiled, then was deleted: both APIs are on the
  compile classpath.
- `./gradlew runGameTestServer` (binds no port) loaded AE2 19.2.18,
  GuideME 21.1.21, FTB Teams 2101.1.11, FTB Library 2101.1.39,
  Architectury 13.0.11, and `tla_archive` 0.1.0, and constructed the mod.
  It then stopped with `No test functions were given!`, which is expected with
  no gametests. `runClient` and `runServer` have **not** been launched.
  `runServer` binds a game port (25565 by default) and needs an allocation
  in `ports.md` first.

## Existing-mod check (design deferred decision)

Brief web search on 2026-10-28 for a maintained NeoForge 1.21.1 mod that
counts current stock across AE2 grids with team credit, matching policies,
and safe consumption. **None found.** The nearest candidates:

- [Museum Curator](https://www.9minecraft.net/?p=794065): an all-items
  checklist with 1.21.1 NeoForge builds. It records one-time collection, keeps a
  single global state, covers only the general form of potions and enchanted
  books, and has no AE2 integration.
- ME Quest Detector (1.21.1 NeoForge port; listing not checked):
  detects AE2 storage and submits items to FTB Quests. That is quest
  submission, not current-holdings counting, and it has no matching policies.
- All Items (server mod) and Item List (NeoForge port) track goals or group
  progress but have no AE2 grid counting.

Conclusion: build `tla_archive` as planned. This was a quick search, not an
audit; revisit only if a candidate appears.
